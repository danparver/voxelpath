# VoxelPath

Un editor web minimalista para crear estructuras y recorridos 3D. Edita sobre una cuadrícula, capa por capa. Guarda tu diseño en un archivo JSON o expórtalo como STL.

### Pruébalo

https://voxel-path.web.app/

![VoxelPath screenshot](src/img/screenshot1.png)

Diviértete creando tus propias estructuras o recorridos 3D.

- Construye capa por capa sobre una cuadrícula 2D.
- Guarda tu creacion en un formato JSON abierto para compartirlo o utilizarlo en otros proyectos.
- Carga diseños existentes desde archivos JSON.
- Exporta tu creación como un archivo STL para impresión 3D.
